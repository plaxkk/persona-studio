# 工作灵感

原创任务可在生成前读取本地工作证据，回复和聊天不读取。默认关闭；在运行状态目录创建私有 `work-inspiration.json` 开启，无需迁移数据库。

```json
{
  "enabled": true,
  "days": 14,
  "repositories": ["/absolute/path/to/project"],
  "codex_db": "/absolute/path/to/codex/state_5.sqlite",
  "memory_files": ["/absolute/path/to/curated-memory.md"],
  "account": "your_handle",
  "style_corpus": "/absolute/path/to/corpus.json"
}
```

每次原创刷新：最多 8 个仓库、每仓库 8 条提交（仅时间、hash、标题，不读 diff）；Codex SQLite 只读查询相同项目路径最近 8 个任务的标题、首条用户消息和预览摘要。它不是完整对话检索，也不支持其他机器或云端聊天。数据库结构不兼容时标记不可用，不阻断草稿。可选记忆文件最多 3 个，每个 2000 字符，作为历史背景而非当日事实。

仅选择主任务，排除子代理与内部审批对话；还会从所选任务的本地会话日志尾部最多 128 KB 提取最近 3 条用户发言（每条最多 800 字符），不读取工具输出。只允许同一 Codex 目录下的 `sessions/*.jsonl` 日志。

风格文件是对象数组，字段为 `author`、`kind`、`text`、`url`；只选配置账号的 `post`，最多 8 条，不使用模型生成草稿作为本人语料。请提供已筛除引用他人正文的语料。

模型观察上下文包含来源、时间、来源状态及证据类型。讨论不能证明任务完成，提交不能证明业务收益。规则要求具体切口、有依据的判断、口语短句，禁止汇报腔和虚构经历；近期草稿用于去重。

这些摘录会传给配置的写作模型。仅配置愿意用于写作的项目和文件；凭据模式、邮箱、本机路径会脱敏，但自动脱敏不保证覆盖所有私人信息。原文不得直接公开，生成结果仍由本人审阅。个人路径、语料和人设配置保存在忽略的本地状态目录，不提交 Git。把 `enabled` 改为 `false` 即可停用；恢复原有 persona 需使用修改前的本地备份。

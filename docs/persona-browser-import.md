# 网页触发本机 X 人设导入

## 实现与边界

Vercel 静态网页 → 固定来源扩展消息 → 已授权本机 API → 独立 Codex 执行槽 → 任务绑定 MCP → 扩展 WebSocket → 专用 X 标签页。模型只选择浏览动作；帖子原文由扩展提取，网页不能提交来源证据。Hermes/OpenClaw 日常写作不变。

`persona_imports.py` 保存批次、动作、来源和候选；版本与风格语料应用使用同一个 SQLite 事务。帖子 ID 始终为字符串。旧版本保留。外部文案只作证据，模型无 cookie、工作室凭据、设备令牌或 shell 工具。

## 专用 Codex

运行 `deployment/install_persona_codex.py`，下载并按 GitHub 官方 release SHA-256 验证 0.156.1。当前 0.137.0 缺少可靠关闭内置图片读取工具的能力，不能作为这个功能的运行时。安装不覆盖个人 CLI。

macOS 使用附加的只收紧权限沙箱，禁止读取个人 AGENTS、技能、插件和 hooks 文件（保留原登录路径，不复制凭据）。Linux 的这层隔离尚未验证，采集器会阻止启动，普通工作室服务不受影响。

忽略用户配置、规则和宿主技能；隔离临时目录，只读沙箱；禁用 shell、图片、内置浏览器、插件、hooks、apps、子代理和通用搜索。模型目录只继承选定模型的基本能力元数据，明确清除模型默认工具。模型名与推理强度固定到批次，不更换供应商。仍有 CLI 的资源发现/请求输入等协议工具，但唯一 MCP 不提供资源，不能访问文件或其他服务。`tests/codex_persona_isolation.py` 在模拟模型端点检查实际发送的工具清单，而非依赖模型自述。

## 运行与恢复

扩展需 1.3.0，新增 scripting 权限；升级后重新加载扩展并授权连接。本机服务升级前备份状态数据库，重启 API 与 worker。旧任务标记为可恢复中断，不自动重试。专用浏览器等待不占用普通写作槽。手动导入可在自动同步暂停时启动，全局暂停会暂停正在运行的导入。

任务目标 20/100/300；默认 300，Codex 优先各采集一半原创/引用附言与回复。真实构成来自解析结果；不足可互补，不保证获取全部历史。30 分钟主动执行、240 个动作；3 次滚动无新增停止等待。登录、验证码、账号不匹配、页面不就绪均等待本人处理。网络断线/扩展重新启动后需继续，不自动重放已发动作。

来源正文与引用上下文分离；纯转帖、广告、译文、未展开全文、无文字材料不进入风格语料。少于 20 条不生成完整人设。蒸馏保留换行，按推文/回复分别计数。候选判断必须引用本次实际帖子 ID；应用前显示版本比较。原始资料 7 天后清理（每小时检查），未应用预览不再可应用，已应用人格及净化风格资料保留。新版常规备份排除临时原帖、profile 与动作快照，保留已应用人格及风格记忆，避免临时材料通过备份超期保留。

## 验证命令

- `.venv/bin/python -m pytest -q`
- `node --test tests/desktop_extension.test.mjs`
- `.venv/bin/python tests/codex_persona_isolation.py`（只连接 loopback 模拟模型）
- `.venv/bin/python tests/persona_browser_dom.py`（模拟 X DOM）
- `.venv/bin/python -m tests.persona_import_e2e`（真实扩展、模拟 X 和模拟模型、临时状态）

真实账号验收必须单独记录：先 20 条，再 300 目标，最终停留在预览。不将模拟测试或本机进程存活描述为真实采集成功。

## 当前验收结果

2026-09-24：102 个 Python 测试、2 个扩展边界测试通过。DOM 模拟测试和 20 条完整模拟导入（10 原创＋10 回复、刷新恢复、显式应用）通过；桌面与 390px 手机宽度已检查。真实 ChatGPT 登录的 gpt-6-astra 最小结构化调用及专用 MCP 进度/结束调用通过（仅模拟账号状态）；工具请求清单及个人指令隔离测试通过。

真实 X 采集尚未运行：需要用户在 Chrome 扩展管理页重新加载 1.3 并授权后，再进行 20/300 条验收。浏览器自动化安全策略禁止代理打开 chrome://extensions，不能绕过。现有人设保持不变。

可选真实模型协议检查：`.venv/bin/python tests/persona_codex_live_smoke.py`，会消耗所选模型额度，但不读取 X 或真实人设。MCP 仅对 `browse/progress/finish` 三个固定工具使用 `approval_mode=auto`，其它工具仍关闭；不以模型声称“完成”代替实际 MCP 完成检查点。
